## Modifications

The original datasets were used for an academic Fake News Detection System project.

The following modifications were made:

1. Assigned numerical labels (1 = Fake News, 0 = Real News).
2. Combined the fake and real news datasets.
3. Removed exact duplicate records.
4. Identified articles with conflicting labels.
5. Randomly shuffled the combined dataset.
6. Generated a processed dataset named `news_dataset.csv`.
